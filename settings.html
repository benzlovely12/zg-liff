การเชื่อมต่อ Google Sheets
วิธีติดตั้ง
  1. เปิด Google Sheets ใหม่ แล้วไปที่ Extensions → Apps Script
  2. วาง Code จากไฟล์ Code.gs ลงใน editor
  3. แก้ไข SPREADSHEET_ID ให้ตรงกับ ID ของ Google Sheet ที่สร้าง
  4. รัน Function setupSheets() เพื่อสร้าง Sheet ทั้งหมด
  5. Deploy → New Deployment → เลือก Web App → ตั้งค่า "Anyone" → Copy URL
  6. นำ URL มาใส่ในช่องด้านบน แล้วกด บันทึก
